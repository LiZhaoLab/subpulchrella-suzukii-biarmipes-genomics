# Effective population size reanalysis: RepeatMasker masks and P98 depth thresholds

Updated: 2026-10-23

## Purpose and final outputs

This directory contains the 2026-10-23 reanalysis of effective population size (Ne) for D. subpulchrella and D. suzukii. It uses short-intron and four-fold degenerate sites, with the read-quality, depth, and masking settings aligned where possible with the RepeatMasker/P98 population-polymorphism analysis.

The final Ne table is:

`results/effective_population_size/effective_population_size_block_bootstrap.tsv`

It contains 20 results: five samples × two chromosome classes (autosome and X) × two neutral-site definitions (short intron and four-fold). The final short-intron definition is **introns 40–65 bp long, using positions 8–30**. Results from the earlier 30–65 bp definition are not final.

## Input data and external dependencies

This directory holds the neutral-site definitions, active scripts, grenedalf outputs, mutation-rate table, and final Ne results. It does **not** contain independent copies of every large upstream input. Rebuilding the analysis from raw inputs still requires:

- Reference genome FASTA and GFF3 files at the paths recorded in `config/species.tsv`.
- Filtered BAMs, sample information, and chromosome-region BEDs from `population_polymorphism/reanalysis_20260821`.
- Sample-specific P98 depth thresholds and combined indel/RepeatMasker masks from `population_polymorphism/reanalysis_20261012_repeatmasker_p98`.
- The installed versions of grenedalf, Python dependencies, and other tools used by the preparation scripts.

The final Ne calculation from the 20 saved grenedalf CSVs and `config/mutation_rates.tsv` does not require the old `Ne_reanalysis_20260825` directory. The active `01_run_grenedalf_neutral_P98_array.sh` and `03_prepare_short_intron_40to65_array.sh` scripts were also updated to read neutral-site files and `config/species.tsv` from this directory rather than from the 2026-08-25 directory.

## Neutral-site definitions

### Short introns

The final short-intron analysis uses positions 8–30 of introns **40–65 bp** long. The lower intron-length bound was changed from 30 to 40 bp so that the selected positions are not close to the far end of the shortest introns. The source BEDs were generated by `02_extract_short_intron_sites_40to65.py` and prepared for autosomal and X analyses by `03_prepare_short_intron_40to65_array.sh`.

Relative to the earlier 30–65 bp definition, the 40–65 bp definition removed 32 introns and 414 candidate sites in Dsub, and 42 introns and 609 candidate sites in Dsuz. The new chromosome-class BEDs contain no sites absent from the older BEDs.

The final analysis BEDs are:

`sites/analysis_sets/{Dsub,Dsuz}.{autosome,X}.short_intron.len40to65.bed`

### Four-fold degenerate sites

The four-fold sites were selected from the longest valid complete CDS per gene using the extraction method preserved in `scripts/provenance_0825/03_extract_fourfold_sites.py`. The source-site files and the autosomal/X analysis BEDs were copied into this directory from the earlier Ne analysis, with byte-for-byte comparisons at the time of copying.

The final analysis BEDs are:

`sites/analysis_sets/{Dsub,Dsuz}.{autosome,X}.fourfold.bed`

An independent rebuild was then performed using the archived Python extractor, the reference FASTA/GFF3 files, and the chromosome-region BEDs. Job **6484472** completed successfully for both species. For each species, the regenerated source BED, site table, summary, selected-CDS table, autosomal BED, and X BED all matched the saved copies. The rebuild reported 2,372,421 source four-fold sites for Dsub and 2,490,882 for Dsuz. These source-site counts are **not** the numbers of sites passing all sample-specific grenedalf filters.

The job logs are `logs/Ne_4foldQC.6484472_{0,1}.{out,err}`. The duplicate regenerated files in `checks/fourfold_rebuild/` may be removed after this successful comparison; the saved source and analysis BEDs, extractor, verification script, and logs should be retained.

## Diversity estimation

`01_run_grenedalf_neutral_P98_array.sh` runs grenedalf separately for each sample, chromosome class, and neutral-site type. Its array has 20 combinations.

Common analysis settings include:

- Properly paired filtered BAM reads; minimum mapping quality 20 and base quality 20.
- A minimum allele count of 2.
- Sample- and chromosome-class-specific P98 read-depth limits.
- The combined indel and RepeatMasker mask from the P98 reanalysis.
- Non-overlapping 20-kb windows, using the grenedalf `valid-loci` window-average policy.
- The corresponding autosomal or X pool size from the sample configuration.

The final ten short-intron CSVs are under `grenedalf_neutral_len40to65/`. They were produced by job **6484366**; all ten tasks completed with exit code 0 and `FINAL: PASS`. The final ten four-fold CSVs are under `grenedalf_neutral/`, in its `fourfold` subdirectories. All 20 CSVs were present when the Ne summary was calculated.

The 20-kb output includes windows with zero passing sites. Such windows do not contribute callable sites to the Ne estimate. The presence of a CSV row does not mean that its window contributed a valid estimate.

## Ne estimation and uncertainty

`08_bootstrap_effective_population_size.py` reads the ten final short-intron CSVs, ten four-fold CSVs, and `config/mutation_rates.tsv`. It aggregates Watterson’s θ across callable sites, then calculates Ne using:

- Autosome: `Ne = θW / (4μ)`
- X chromosome: `Ne = θW / (3μ)`

The primary mutation rate is `3.3 × 10⁻⁹` per site per generation. The table also includes sensitivity estimates for mutation rates `2.8 × 10⁻⁹` and `5.49 × 10⁻⁹`. Uncertainty is estimated with 10,000 chromosome-aware bootstrap replicates of 1-Mb blocks, using random seed `20260826`.

Job **6484447** read 20 CSVs, wrote 20 result rows, and finished with `FINAL: PASS`. Its output is the final Ne table named above. The script number `08` was retained from the earlier workflow; the number is a filename convention, not an additional analysis step between scripts `04` and `08`.

## Relationship to the 2026-08-25 analysis

`Ne_reanalysis_20260825` is a provenance source, **not** the final Ne result directory. Necessary four-fold source files, chromosome-class BEDs, selected-CDS tables, configuration, and extraction scripts were copied into this 2026-10-23 directory. The four-fold files were subsequently regenerated and verified to match.

The old Ne result table should not be combined with the final 2026-10-23 table. Differences between those analyses may reflect multiple changes, including P98 depth limits, RepeatMasker masking, and—in the short-intron analysis—the 40–65 bp length criterion. Comparing the two final tables alone does not isolate the effect of any one change.

Do not delete the shared upstream genome, BAM, mask, or region files merely because the 2026-08-25 Ne directory is no longer needed for the active calculation.
